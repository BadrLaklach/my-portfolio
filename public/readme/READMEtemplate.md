## About

Software Engineering and Intelligent Systems student at ENSAM Meknes, building applied AI, cloud-native, full-stack, mobile, and XR products.

## Technical stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS 4
- **Animation**: Three.js and React Three Fiber
- **Contact**: Nodemailer API route with a direct email fallback
- **Internationalization**: Automatic French/English browser detection
- **Deployment**: GitHub Pages

## Features

- Interactive 3D background effects
- Responsive layouts for mobile, tablet, and desktop
- Dark/light theme with persisted preference
- Bilingual French/English interface
- SEO metadata, sitemap, robots.txt, and JSON-LD
- Legal notice and privacy policy pages

## Featured projects

- **HawQ-ai XR / MRAF** - Unity and Meta Quest 3 workflow for digital-twin visualization and spatial relocalization.
- **DokuMind** - Collaborative multi-tenant knowledge-management SaaS with semantic retrieval and grounded streaming chat.
- **Agile Microservices** - Spring Boot services, API Gateway, JWT, RabbitMQ, PostgreSQL, MongoDB, React, Docker, and Kubernetes.
- **DariPredictor** - Moroccan real-estate valuation platform with ensemble machine learning and a FastAPI/React stack.
- **XP-FIT** - Gamified Flutter fitness and nutrition application.
- **Smart Office IoT** - Cisco Packet Tracer network and automation simulation.
